# XING MUSE — 星缪斯

Personal creative portfolio website.

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/ (root)**, then Save.
4. Wait for the deployment URL to appear in the Pages panel.

## Before public launch
- Replace the designed project placeholders in the work cards with approved high-resolution project images.
- Replace the placeholder email address in the contact section.
- Review all public-facing personal information and project descriptions.

The project artwork panels currently serve as layout/visual placeholders, not representations of final portfolio deliverables.
